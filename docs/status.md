# OpenCut 0.0.1-beta 状态

Rust workspace 与插件版本统一为 `0.0.1-beta`。当前候选要求 Intel Mac 和 macOS 26 或更新版本，与包内 FFmpeg 的最低系统要求一致；应用声明和命令行安装器使用同一系统门槛。安装器支持不带数字后缀的 beta；版本编号重置通过显式安装保留选定工作区。校验文件使用相对文件名，构建路径进行映射；媒体依赖、许可证和来源证明按固定清单校验。

| 平台 | 当前状态 |
| --- | --- |
| macOS Intel | CLI、Worker 和桌面应用已构建；隔离安装、真实服务、MCP、原生导出及限定浏览器验收通过 |
| macOS Apple Silicon | 用户明确延后至更换硬件后验证，不阻塞本轮 Intel 发布；不宣称已经验收 |

生成与规范契约检查通过：185 个操作、12 个领域。架构测试 14 项、插件运行测试 7 项、插件包测试 6 项、本地包测试 8 项、原生依赖装配测试 5 项、发布保护测试 6 项及源码卫生测试 5 项通过，架构及契约边界检查通过。源码卫生扫描覆盖 3470 个待发布文件；不包含 Git 历史和忽略文件。

隔离安装、重复安装、诊断和真实服务启动通过。已通过安装后的 MCP 启动入口检查 11 个领域工具、素材导入、计划/原子应用、幂等重放、封面保存和原生 MP4 导出；独立 FFmpeg 像素对照通过。当前候选复用同一合成工程与已验收导出，没有重新生成用户素材或媒体任务。

Chrome 中，实际界面通过素材导入与放置、超过 4 秒的原生连续画面、真实音频工作器采样、暂停/继续/跳转、重命名与撤销/重做、页面重新加载和服务重启。相同运行时的无界面和可见窗口模式均通过。连续画面与独立红/绿预期值相符；4096 帧 PCM 与浏览器固定母带参数参考的最大绝对误差为 0。证据绑定确切 ZIP、完整运行时清单、CLI、Worker、浏览器和验证脚本身份；这些检查不代表持续帧率、物理听感或全产品验收。

发布资产保留在 `dist/releases/0.0.1-beta-public`，与此前验收包分开保存。命令行安装器使用包内 Node 的隔离安装通过；桌面包的严格 ad-hoc 签名、ZIP 完整性、嵌套包与安装器身份、最低系统声明和外壳内容卫生检查通过。当前候选哈希见 [status.json](status.json)。
