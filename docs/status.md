## 实现范围

已有工程与因果历史、素材导入、多轨剪辑、文字字幕、图形效果、混合蒙版、转场、固定修订预览与输出、授权资源、任务取消恢复和工程包。来源解码器、数据库升级、许可证和固定依赖证明属于必要支持代码。GPUI Desktop 仍是独立壳。

工程封面通过现有 `cover_set` 原子编辑保存，CLI、HTTP、MCP、SDK 与 Web 共用 Rust 合同。支持源视频选帧、选择或上传图片、恢复自动封面。选帧不包含时间线特效和标题，封面图片可以不放入时间线。项目卡片保持 16:9、流式列宽，单项目沿用普通卡片尺寸。悬停提示延迟一秒；时间线跟随实际输出播放头，暂停、拖动和手动导航期间让出滚动控制。

旧浏览器 Classic 恢复功能已退出；已有工程、历史和共享渲染能力继续保留。营销网站、博客、云账户和 SEO 页面不在本地剪辑工具范围内，整页内存 BFCache 恢复也不在支持范围内。

## 本地插件预发布候选

项目以 **OpenCut Plugin** 名称提供 GitHub 本地插件包，包含标准插件元数据、MCP 启动入口、编辑技能、校验安装器、基础诊断和 Web 服务助手。它是独立维护的 OpenCut 社区分支，不属于上游官方发行，也未提交官方插件目录。当前包目标为 macOS Intel；Node、FFmpeg 和对应 Chromium 仍是外部依赖。

本轮集成程序已完成 release 构建、184 个操作及 12 个领域的生成合同/规范核对。Python 测试 50 项、架构测试 14 项及边界检查通过。自动输出预算修正通过数据库增长回归和实际 64 MiB 小容量卷检查：保留独立控制写入余量，并为实际输出文件增长留空间，未设置固定 512 MiB 文件上限。已有显式用户配额继续生效。

安装包、stdio MCP 合成流程、导出及独立像素探针以 GitHub 预发布版的逐包校验报告为准，不能从构建结果推定通过。未标记完整交付；早期合成 H264 红色探针观测 RGB 254/23/0，仍未通过绿色分量小于 15 的原门槛。干净机器和实际 ChatGPT 客户端对话尚未验收。人工截图只展示界面，不作为行为验收证据。

## 已知限制

- 完整导出像素/性能、任意编辑与 seek、故障恢复、大工程、长片、多设备、多浏览器和物理输出矩阵尚未全部验证。
- 未缓存实时预览曾出现 568.7 毫秒停顿。AVC 缓存是有损预览：独立单帧探针通过 PSNR 30 dB 门槛，但 SSIM 为 0.947518，未通过 0.98；严格像素验收仍开放。
- 长源完整播放存在进程树驻留内存超额问题；macOS 使用监测后终止，不能宣称内核硬配额。
- 一次母带后 PCM 高 DC 残差的原因未确定；实时与导出采样策略的完全等价尚未全部验证。
- 逐字体、平台、预算、持续帧率和可选音效提供方的故障/取消/期限组合覆盖不完整。
- 工程包依赖、分支合并、故障矩阵、签名、安装、升级及跨平台发行尚未全部验收。
- 部分保留的组合/兼容性验收脚本仍有旧接口假设，不能算作当前候选已通过。测试入口和不可变兼容性夹具不会仅因未被默认组合验收调用而删除。

## 性能优化候选（2026-10-28）

已优化同素材远距离跳转、缩略图可见请求调度与字节解析、共享源读取转换和持续视频的私有 RGBA 桥接。真实浏览器合成源的远跳由 615–1050 ms 降至 6–12 ms；4K 桥接中位耗时降低约 26%，不代表完整导出提速。相关视觉、音频、来源图与 Web 测试共 350 项及独立 Web 构建通过；复用同一 CLI 完成生成和规范核对，没有重建 Rust。
