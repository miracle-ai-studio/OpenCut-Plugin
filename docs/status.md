# OpenCut 0.0.1-beta 状态

Rust workspace 与插件版本统一为 `0.0.1-beta`。安装器支持不带数字后缀的 beta；版本编号重置通过显式安装保留选定工作区。校验文件使用相对文件名，构建路径进行映射；媒体依赖、许可证和来源证明按固定清单校验。

| 平台 | 当前状态 |
| --- | --- |
| macOS Intel | CLI、Worker 和桌面应用已构建；安装及静态检查通过，真实服务验收受当前执行环境权限限制 |
| macOS Apple Silicon | 用户明确延后至更换硬件后验证，不阻塞本轮 Intel 发布；不宣称已经验收 |

生成与规范契约检查通过：185 个操作、12 个领域。架构测试 14 项、插件运行测试 7 项、插件包测试 6 项、本地包测试 8 项、原生依赖装配测试 5 项通过，架构及契约边界检查通过。发布保护测试覆盖上传失败保留旧版本、文件身份核验和版本比较。

隔离安装、重复安装及诊断通过。真实服务启动返回 `SERVICE_ERROR / Operation not permitted`，因此本轮未完成真实 MCP、剪辑、导出或人工验收。桌面包通过严格 ad-hoc 签名、ZIP 完整性和相对校验文件检查；尚未完成 Developer ID 签名或公证。

源码发布分支为 `release/0.0.1-beta`。本轮默认构建 Intel；可在以后手动启用 Apple Silicon。发布流程先核验所选平台的完整资产，再发布新版本，仅在本次操作明确选择清理时删除旧 0.5.0 beta Release 及标签。GitHub Release 和旧版本清理目前仍待执行，完整交付保持 **false**。

公开状态仅保留当前产品的构建、验证范围和限制，不包含私人项目、工作区、机器目录或历史产物清单。详细状态见 [status.json](status.json)。
